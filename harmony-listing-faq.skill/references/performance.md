# 性能上架检测标准（11项）

### 【上架检测FAQ】应用或元服务启动加载完成快
- 标准：冷/温启动在合理时延内完成首屏可用，启动过程无长时间黑白屏、无响应。
- 常见失败：启动期同步加载过多模块；首帧前阻塞主线程；未用启动框架编排。
- 修改要点：AppStartup/延迟加载；首屏只做必要初始化；大图与网络后置；Profiler 看启动耗时。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0201202130504096616

### 【上架检测FAQ】应用或元服务内点击操作完成快
- 标准：点击后业务结果在合理时延内完成（打开页、提交、播放等），无明显长时间等待无反馈。
- 常见失败：点击后无 loading 且长时间无结果；主线程处理重逻辑导致完成慢。
- 修改要点：异步化业务；即时反馈（loading/禁用态）；减少点击路径同步 IO。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203203100423940948

### 【上架检测FAQ】应用或元服务内点击操作响应快
- 标准：点击后交互反馈及时（按下态/涟漪/状态变化），不感觉「点了没反应」。
- 常见失败：无按下态；点击后 UI 卡住才跳转。
- 修改要点：先更新 UI 再异步任务；控件提供 pressed 态；避免点击回调内同步重计算。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0202203100544653696

### 【上架检测FAQ】应用或元服务内滑动过程流畅
- 标准：列表/页面滑动过程帧率稳定，无明显卡顿、掉帧、拖影。
- 常见失败：`build` 过重；列表项复杂且无复用；滑动中解码大图。
- 修改要点：`LazyForEach`/组件复用；减 nested scroll；滑动中降载；Trace 查掉帧。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0202203100681626697

### 【上架检测FAQ】在线短视频类应用，视频切换时起播快
- 标准：短视频切换后起播时延满足体验标准，切换无明显长时间黑屏/转圈。
- 常见失败：无预加载；每次切换全量重建播放器；码流选择不当。
- 修改要点：邻片预加载；播放器复用；首片优先起播再补清晰度。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0202203100799445698

### 【上架检测FAQ】在线长视频类应用，视频切换时起播快
- 标准：长视频选集/切集起播快，符合长视频场景体验要求。
- 常见失败：切集重新缓冲过久；无起播超时与降级策略。
- 修改要点：缓冲策略与码率自适应；切集复用播放管线；展示明确缓冲反馈。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203203100905620949

### 【上架检测FAQ】在线短视频类应用Seek操作播放快
- 标准：短视频 Seek 后快速恢复播放，无明显长时间停顿。
- 常见失败：Seek 后重新拉取整段；关键帧索引缺失导致慢。
- 修改要点：支持精准/关键帧 Seek；本地缓冲段优先；Seek 中保持 UI 状态。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203203874498496002

### 【上架检测FAQ】在线长视频类应用Seek操作播放快
- 标准：长视频拖动进度后快速续播，符合长视频 Seek 体验。
- 常见失败：大文件 Seek 卡顿；进度条拖动与画面严重不同步。
- 修改要点：分段缓冲/索引；拖动预览与松手 Seek 分离；避免主线程解析。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0202203874667721063

### 【上架检测FAQ】应用在线流媒体播放过程流畅
- 标准：在线流媒体播放过程流畅，卡顿率、卡顿时长在可接受范围。
- 常见失败：码率过高导致频繁卡顿；缓冲策略不当；网络切换无处理。
- 修改要点：ABR；合理缓冲水位；弱网降级；监听网络变化重连。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0208203874811292056

### 【上架检测FAQ】应用或元服务应用内转场操作流畅
- 标准：页面转场动画流畅，无掉帧、闪白、布局跳动。
- 常见失败：转场同时做重布局/大数据绑定；自定义动画过重。
- 修改要点：转场完成后再加载重内容；用系统 Navigation 转场；避免转场中同步网络。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0204208173222914070

### 【上架检测FAQ】应用或元服务内滑动操作响应快
- 标准：滑动手势跟手，响应延迟低，无明显迟滞。
- 常见失败：触摸事件被重逻辑阻塞；嵌套手势冲突导致跟手差。
- 修改要点：触摸路径轻量化；减少滑动中 JS 繁重工作；处理好嵌套滚动优先级。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203208172603985061
