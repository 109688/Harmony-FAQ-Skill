# 安全上架检测标准（16项）

### 【上架检测FAQ】广告关闭按钮是否过小
- 标准：广告关闭按钮尺寸与热区足够，用户可明确、方便地关闭广告。
- 常见失败：关闭按钮过小难点；热区远小于可视图标。
- 修改要点：关闭控件满足点击热区下限（参见 UX 点击热区）；明显可见对比。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203198798753757050

### 【上架检测FAQ】面向儿童的应用提供针对儿童的隐私政策
- 标准：面向儿童的应用须提供针对儿童的隐私政策说明。
- 常见失败：儿童应用仅通用隐私政策；缺失儿童专章。
- 修改要点：儿童受众单独隐私政策入口；收集原则最小化并明示。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0214202124733974911

### 【上架检测FAQ】虚假广告
- 标准：广告内容真实，不得虚假宣传、误导功能或效果。
- 常见失败：广告承诺与落地不符；伪装系统通知诱导点击。
- 修改要点：审核广告素材与落地页一致；禁用误导样式。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0214202128755511917

### 【上架检测FAQ】应用广告不得诱导收集个人信息
- 标准：广告不得诱导用户非必要提供个人信息。
- 常见失败：广告流程强索通讯录/定位等与广告无关信息。
- 修改要点：广告链路最小化权限；与业务授权分离；合规 SDK 配置。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203202130021651543

### 【上架检测FAQ】名称图标一致性检测
- 标准：应用名称与图标在包内配置、桌面展示与上架信息保持一致、可识别。
- 常见失败：多处 label/icon 不一致；上架名与包内名不符。
- 修改要点：统一 `app.json5`/`module.json5` label 与 icon；与 AGC 信息对齐。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0214198798960000231

### 【上架检测FAQ】应用不得隐藏最近任务列表
- 标准：不得隐藏或规避系统最近任务列表对应用的正常展示/管理。
- 常见失败：异常 excludeFromRecents 或等效规避导致用户无法从多任务管理。
- 修改要点：移除不合理隐藏多任务的配置/实现；保留系统任务管理能力。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0201200867700468954

### 【上架检测FAQ】个人信息标签与实际应用收集数据保持一致性
- 标准：上架填写的个人信息收集标签与实际代码/SDK 收集行为一致。
- 常见失败：声明未收集但实际收集；少报/错报数据类型。
- 修改要点：盘点所有采集点与三方 SDK；AGC 标签与隐私政策同步更新。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0201170439872944967

### 【上架检测FAQ】广告标识尺寸过小
- 标准：广告「广告」标识尺寸足够清晰可辨。
- 常见失败：标识过小或对比度不足形同未标。
- 修改要点：按广告标识规范设置最小尺寸与对比；勿被其它 UI 遮挡。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0214201777310659600

### 【上架检测FAQ】检测应用广告是否提供正常关闭按钮
- 标准：可关闭类广告必须提供可正常工作的关闭按钮。
- 常见失败：无关闭；关闭无效；关闭后立刻再弹同一广告强干扰。
- 修改要点：关闭回调真正 dismiss；倒计时结束后仍须可关；联调广告 SDK。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203201777673996240

### 【上架检测FAQ】检测应用是否频繁弹出广告
- 标准：广告弹出频率合理，不得频繁打断主流程。
- 常见失败：启动/返回/滑动过度弹窗广告。
- 修改要点：控制插屏频次与场景；主路径少打断；遵守审核指南广告条款。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0201201777762392287

### 【上架检测FAQ】是否含有与未成年人年龄不相符的广告
- 标准：面向或可能触达未成年人的应用，广告内容须与年龄适宜。
- 常见失败：儿童/学生向应用出现成人向广告。
- 修改要点：广告投放年龄定向与内容分级；儿童模式关闭不合规广告源。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0203201777832950241

### 【上架检测FAQ】需要正确设置发布版本应用调试属性
- 标准：发布上架包须为非调试版本（debug 关闭）。
- 常见失败：release 包仍 `debug: true` 或调试签名属性残留。
- 修改要点：发布构建关闭 debug；检查 app/module 与签名类型；预检该项。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0204206355130657080

### 【上架检测FAQ】禁止应用或元服务设置错误图标图片格式
- 标准：图标资源格式符合要求，不得使用错误/损坏格式。
- 常见失败：错误扩展名；非规范格式导致展示异常。
- 修改要点：按规范使用 PNG 等允许格式；分层图标资源有效；预检验证。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0207208709754305264

### 【上架检测FAQ】应用或元服务名称应该清晰准确
- 标准：名称清晰准确，能反映应用，无故意混淆、堆砌关键词。
- 常见失败：名称与功能严重不符；仿冒系统/其它应用命名。
- 修改要点：修正 label 与上架名称；避免误导性命名。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0207208711060769265

### 【上架检测FAQ】个人开发者支付SDK接入检测（微信、支付宝）
- 标准：个人开发者接入微信/支付宝等支付 SDK 须符合平台与上架对主体/资质的要求。
- 常见失败：个人主体违规接入；支付能力与账号类型不匹配。
- 修改要点：按 AGC/支付平台规则确认主体资质；不合规则移除或升级企业主体。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0208209385054155500

### 【上架检测FAQ】禁止应用频繁申请权限
- 标准：权限申请时机合理、频率克制，不得频繁弹授权干扰用户。
- 常见失败：启动连环申请；拒绝后立即重复弹；无关场景申请。
- 修改要点：按需在用时申请；尊重拒绝结果；合并说明 reason；最小化权限集。
- 源：https://developer.huawei.com/consumer/cn/forum/topic/0201210073390277507
