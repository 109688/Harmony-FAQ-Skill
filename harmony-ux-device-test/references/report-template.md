## 严重级别速查

- **P0**：无法启动、主流程崩溃、数据损坏（多对应 50104 §3.1）
- **P1**：核心功能不可用、结果错误、隐私/广告硬伤（§3 / §5 / §7）
- **P2**：次要功能失败或明显体验缺陷（含上架 UX FAQ）
- **P3**：轻微 UI/文案问题
