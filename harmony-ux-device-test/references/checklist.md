# 真机用户体验检查清单

按模块勾选；每项至少完成「进入 → 主操作 → 返回/关闭」。  
条款对照见 [official-standards.md](official-standards.md)（[50104](https://developer.huawei.com/consumer/cn/doc/app/50104) / [50106](https://developer.huawei.com/consumer/cn/doc/app/50106) / [上架检测专题](https://developer.huawei.com/consumer/cn/forum/subject/2114199480637425001)）。

## 启动与首屏

- [ ] 冷启动成功，无闪退（50104 §3.1；审核 FAQ）
- [ ] 启动时长可接受；无明显长时间黑/白屏（上架检测·启动）
- [ ] 隐私政策可打开；同意/拒绝路径清晰（§7.1–7.5）
- [ ] 引导页可跳过或滑完，不会卡死
- [ ] 首屏主 CTA 可点且有即时反馈（上架检测·点击响应）
- [ ] 首次启动不频繁连环弹敏感权限（§7.22）

## 导航结构

- [ ] 全部 Tab / 底栏入口可进入
- [ ] 当前 Tab 高亮正确
- [ ] 二级页标题正确，返回键回到预期页
- [ ] 侧滑返回（若系统支持）不误关关键流程
- [ ] 深链/通知入口（若有）落地页正确

## 列表与内容

- [ ] 有数据：列表展示正常，图片/文案不错乱
- [ ] 空态：有说明与下一步（非纯白屏）
- [ ] 滚动流畅，滑到底无异常翻倍/错位
- [ ] 下拉刷新（若有）有结束态
- [ ] 详情页打开/返回后列表位置合理

## 搜索 / 筛选 / 排序

- [ ] 搜索框可聚焦、可输入、可清除
- [ ] 有结果 / 无结果提示正确
- [ ] 筛选条件生效且可重置
- [ ] 排序切换后列表变化符合预期

## 表单与提交

- [ ] 必填校验在提交前或提交时明确提示
- [ ] 非法输入有可读错误，不静默失败
- [ ] 键盘不永久遮挡主按钮（可滚到可见）
- [ ] 提交中有 loading，防重复乱点导致多次提交（尽量验证）
- [ ] 成功/失败均有用户可读反馈

## 账号与权限

- [ ] 登录/注册/退出（有则测；无账号则标未测）
- [ ] 权限「允许」后功能可用
- [ ] 权限「拒绝」后有引导或降级，不死循环弹窗
- [ ] 设置里可再次触发权限说明（若产品提供）

## 设置与其它入口

- [ ] 关于/版本信息可读
- [ ] 反馈/客服/分享入口可打开且可返回
- [ ] 清除缓存等危险操作有确认（测到确认即可）
- [ ] 主题/语言/通知开关（若有）切换生效

## 系统交互

- [ ] 返回键逐步退出，不直接杀进程（除非在根页）
- [ ] Home 后再进，状态基本恢复
- [ ] 横竖屏/折叠（产品声明支持时）布局可用
- [ ] 来电/通知遮挡后回前台不崩溃（抽测）

## 广告 / 推送（有则测，50104 §5 / §3.7）

- [ ] 广告可识别（「广告」标识）
- [ ] 关闭按钮明显有效，关后不连环弹
- [ ] 不在点返回/Home 时恶意弹广告；退出后不再弹
- [ ] 推送/弹窗可关闭且标明来源应用

## 体验红线（上架检测 FAQ → `harmony-listing-faq`）

- [ ] 无大面积文案截断、控件重叠、热区过小导致误触
- [ ] 对比度可读（浅字浅底等明显问题记下）
- [ ] 底部手势/导航条不遮挡主按钮；挖孔/状态栏不挡返回与标题
- [ ] 侧滑返回可用，不与全屏手势死锁
- [ ] 无明显连续掉帧或点击后 >3s 无反馈

## 记录约定

- 通过：简短记「OK」
- 失败：立即按主 SKILL 缺陷模板输出，并在此勾「失败」+ 缺陷标题
- 跳过：写原因（无账号 / 需实付 / 入口灰掉）
