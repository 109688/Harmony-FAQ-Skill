## A. 审核指南 · 真机必测（蒸馏自 50104）

### A1 应用功能（§3）— 全功能覆盖核心

| 条款要点 | 真机怎么验 | 建议级别 |
| --- | --- | --- |
| 可安装、启动、卸载；无频繁崩溃/闪退/无响应 | 冷启、走主路径、返回/杀进程再进 | P0 |
| 注册/登录无异常（验证码、帐号不可用等） | 有帐号体系则完整走登录；需演示帐号问用户 | P0/P1 |
| 功能已实现且可用；非测试版、无「开发中」空壳模块 | **每个入口点开**；灰显/占位/空白记缺陷 | P0/P1 |
| 不得虚假/误导功能 | 入口承诺与实际结果对照 | P1 |
| 推送/弹窗：可关闭；标明提供者；勿扰关闭 | 有通知/弹窗则测关闭与标识 | P1/P2 |
| 主功能付费才可用 → 需免费体验；限制付费前明示 | 付费墙路径读文案与体验入口 | P1 |
| IPv6 环境可运行（有条件时） | 可选抽测 | P2 |

### A2 应用安全（§2）— 体验侧可见项

| 条款要点 | 真机怎么验 | 建议级别 |
| --- | --- | --- |
| 返回键可退出/逐级返回，功能键不失灵 | 各层 `keyEvent Back` | P0 |
| 不伪装系统通知/警告诱导操作 | 观察弹窗样式与文案 | P1 |
| 不隐藏最近任务、不恶意悬浮打扰 | 多任务列表可见；桌面无异常挡操作弹窗 | P1 |
| 未授权不强制开蓝牙/GPS 等 | 观察系统开关是否被悄改；权限前因后果 | P1 |

### A3 广告（§5）

| 条款要点 | 真机怎么验 | 建议级别 |
| --- | --- | --- |
| 标明「广告」；可识别 | 截图读图 | P2 |
| 不恶意频繁弹；不在返回/Home 时弹；不退应用后还弹；不锁屏广告 | 走返回/Home/退出路径观察 | P1 |
| 关闭按钮明显有效；非假关闭/过小/延时才可关；关后不连环弹 | 点关闭并截图前后 | P1 |
| 不整屏误触跳转；下载需明示并主动确认 | 广告点击路径 | P1 |

### A4 用户隐私（§7）— 启动与权限路径

| 条款要点 | 真机怎么验 | 建议级别 |
| --- | --- | --- |
| 应用内可便捷打开隐私政策，链接可用 | 设置/首次启动找入口并打开 | P1 |
| 收集前同意；同意自愿明确 | 首次启动隐私弹窗：同意/不同意路径 | P0/P1 |
| 可撤销同意；帐号体系提供注销 | 设置中查找撤销/注销入口 | P1 |
| 权限最小化、场景相关；拒绝后有降级 | 允许/拒绝各测一遍；拒绝后是否死循环弹窗 | P1 |
| 敏感权限单独同意与必要性说明 | 相机/定位/通讯录等弹窗文案 | P1 |
| 个性化广告可独立关闭（若有） | 设置项抽查 | P2 |

### A5 付费（§6）— 不代付，只验明示

| 条款要点 | 真机怎么验 | 建议级别 |
| --- | --- | --- |
| 价格清晰；购买与支付需明确确认 | 走到确认页为止（默认不真付） | P1 |
| 自动续费条款与取消说明醒目 | 订阅页读图 | P1 |
| 有效联系方式（客服/电话/邮箱） | 「我的/关于/帮助」查找 | P2 |

### A6 应用信息一致性（§1，真机可抽）

| 条款要点 | 真机怎么验 | 建议级别 |
| --- | --- | --- |
| 安装后名称/图标与上架信息、包内一致 | 桌面图标与应用内标题对照 | P2 |
| 需帐号才能用 → 应提供演示帐号（提审场景） | 无帐号阻塞时标注「需演示帐号」 | 阻塞 |

## B. 应用审核 FAQ（50106）

开测与报障时打开 [50106](https://developer.huawei.com/consumer/cn/doc/app/50106)，优先对齐：

- 启动闪退 / 白屏 / 无法启动
- 功能点击无响应、主功能未完善、「开发中」
- 权限最小化与受限权限场景
- 其它当前 FAQ 置顶驳回项

FAQ 与 50104 冲突时：**以现行页面为准**，缺陷里注明「据审核 FAQ：…」。

## C. 上架检测 FAQ 专题（真机 UX/性能/稳定）

专题：[上架检测FAQ专题](https://developer.huawei.com/consumer/cn/forum/subject/2114199480637425001)

真机手测时**强制抽查**下列体验红线（细则与源链见 `harmony-listing-faq`）：

| 分类 | 抽查点 |
| --- | --- |
| UX | 布局不错乱截断；底栏/手势条不挡主按钮；挖孔/状态栏不挡返回与标题；热区可点；侧滑可返回；深色模式（若切）可读 |
| 稳定 | 无崩溃、无卡死/冻屏 |
| 性能 | 启动不过久黑白屏；点击有即时反馈；列表滑动不明显卡顿 |
| 安全检测项 | 广告可关且热区够；不频繁弹广告；名称图标一致性 |

完整条文索引：`harmony-listing-faq/references/INDEX.md`。
